# NaviDent — новый сайт

Адаптивный сайт стоматологической клиники на HTML, CSS и JavaScript. Подходит для GitHub Pages.

## Файлы
- `index.html` — структура сайта и тексты
- `style.css` — оформление, адаптация под мобильные устройства
- `script.js` — ссылки на WhatsApp/Instagram и мобильное меню

## Перед публикацией
Контакты уже добавлены в `script.js`: WhatsApp +7 778 563 04 13 и Instagram @navi_dent_alfarabi. При необходимости их можно изменить там же.

```js
const NAVIDENT_CONTACTS = {
  whatsapp: "https://wa.me/77785630413",
  instagram: "https://www.instagram.com/navi_dent_alfarabi/"
};
```

Для WhatsApp укажите номер в международном формате без `+`, пробелов и скобок. Для Instagram укажите ссылку на профиль клиники.

## Публикация на GitHub Pages
1. Создайте новый репозиторий на GitHub.
2. Загрузите содержимое папки проекта (не сам ZIP).
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.

Через некоторое время GitHub Pages выдаст ссылку на опубликованный сайт.
